# SoNovel for macOS

用 SwiftUI 构建的小说搜索和下载工具，适用于 macOS 14 或更新版本。应用使用系统网络和网页解析框架，打包后可独立运行。

## 构建与打开

安装 Xcode 15.3 或更新版本，再在仓库根目录运行：

```sh
./macOS/build-app.sh
open macOS/dist/SoNovel.app
```

脚本会为当前 Mac 的架构生成并签名 `SoNovel.app`。可以用 Xcode 打开 `macOS/Package.swift` 开发，或进入 `macOS` 目录运行 `swift test`。

## 使用

1. 在搜索框输入书名或关键词，按回车开始搜索。各书源返回时，结果会陆续出现在表格中。
2. 选择一条结果，点击「下载全部」保存该书源当前目录中的所有章节。输入起止序号后，可以只下载所选区间。序号从 1 开始，包含两端，以书源目录顺序为准。
3. 按 `⌘,` 打开偏好设置，可选择保存位置、EPUB / TXT / HTML / PDF，以及是否额外保存逐章 TXT。默认保存位置是「下载」下的 `SoNovel` 文件夹，格式为 EPUB。
4. 关闭主窗口后，仍可从菜单栏的图标重新打开。使用 `⌘Q` 或菜单中的「退出」结束应用。

下载按书源的并发上限运行，书源未指定时最多同时下载 16 章。若部分章节失败，点击「失败详情」可查看原因，点击「重试失败章节」可补下缺章。已下载的正文会保留在当前运行的应用里，等所选章节齐全后再导出。

## 书源

构建时把 `bundle/rules` 中的书源规则打包进应用。聚合搜索使用 `main.json`，搜书按钮旁的「书库网站」列出所有已收录站点的主页。搜索报错时，可以从列表打开对应主页，在站内手动搜索。
